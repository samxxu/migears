HTTPHTTP

Routing, request handling, and access control at the edge.路由、请求处理与边缘访问控制。

migears/web

Packagist 2.1.0

File-as-routing REST framework; MiRest is also the PSR-11 container.以文件为路由的轻量 REST 框架；MiRest 同时是 PSR-11 容器。

Use when适用

  • You need HTTP routing or a JSON API.
  • You want routes to be files and services wired in one place.
  • 需要 HTTP 路由或 JSON API。
  • 希望路由就是文件，服务在一个地方接线。

Avoid when不适用

  • CLI-only tools or long-running workers.
  • You need a full MVC stack with an ORM and a middleware ecosystem.
  • 纯 CLI 工具或常驻 worker。
  • 需要带 ORM 和中间件生态的完整 MVC 栈。

View视图

Turning data into HTML, from native templates to declarative pages.把数据变成 HTML，从原生模板到声明式页面。

migears/template

Packagist 2.0.0

Native PHP template engine with auto-escaping and layout inheritance.原生 PHP 模板引擎，自带自动转义与布局继承。

Use when适用

  • Any server-rendered HTML.
  • You know PHP and want no new template language.
  • 任何服务端渲染的 HTML。
  • 你会 PHP，不想再学一门模板语言。

Avoid when不适用

  • You need declarative page definitions; use yaml-pages or xml-pages.
  • API-only projects with no HTML output.
  • 需要声明式页面定义；应改用 yaml-pages 或 xml-pages。
  • 只输出 API、没有 HTML 的项目。

migears/pages

Packagist 2.0.0

Core declarative page DSL compiled to template files; the shared compiler behind yaml-pages and xml-pages.声明式页面 DSL 的核心编译器，编译为模板文件；yaml-pages 与 xml-pages 的共享底座。

Use when适用

  • You prefer the array DSL and want to define pages in PHP.
  • You are building a parser or front-end package on top of the array DSL.
  • 你偏好数组 DSL，想用 PHP 定义页面。
  • 你要在数组 DSL 之上实现自己的解析器或前端包。

Avoid when不适用

  • You want a ready-made file format; yaml-pages and xml-pages provide one.
  • 你希望使用现成的文件格式；yaml-pages 与 xml-pages 提供了这种格式。

Pulls in:会带入： migears/template

All three page front-ends are valid. pages is the array DSL; yaml-pages and xml-pages are file formats. Pick by preference.三种页面前端都可用。pages 是数组 DSL；yaml-pages 与 xml-pages 是文件格式。按喜好选择。
